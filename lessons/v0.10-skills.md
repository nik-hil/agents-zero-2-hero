# v0.10-skills — On-demand skills

> **Pillar:** 🔧 Toolkit
> **Adds:** `SkillLibrary` + `list_skills` / `load_skill` tools (Claude-style `SKILL.md`)
> **Builds on:** `v0.9-compaction`

## The idea

You want the agent to know a lot — house style, commit conventions, deploy
runbooks — but you *don't* want all that text in every prompt (it's expensive and
distracting, and compaction would just throw it away). Skills solve this:

- Each skill is a Markdown file: `skills/<name>/SKILL.md`.
- The agent always sees a cheap **catalog** — just each skill's name +
  description — injected into the system prompt.
- When a task matches a skill, the agent calls **`load_skill(name)`** to pull the
  full body *on demand*.

So you can have dozens of skills for the price of a one-line catalog entry each.
This is the same idea as `remember` (memory) but for *reusable knowledge* rather
than run-specific facts.

## Anatomy of a skill

```markdown
---
name: python-style
description: How to write clean, idiomatic Python for this project.
---
# Python style
...the actual guidance the agent follows...
```

The frontmatter (`name`, `description`) feeds the catalog; the body is what
`load_skill` returns.

## How to understand this lesson

1. **`skills.py`** — `SkillLibrary` discovers `skills/<name>/SKILL.md`, parses the
   frontmatter for the catalog, and only reads a full body when `load()` is called.
   `_parse_frontmatter` is the little `--- ... ---` splitter.
2. **`coding_agent.py`**:
   - `SKILLS = SkillLibrary(PROJECT_ROOT / "skills")` at import;
   - two new tools, `list_skills` / `load_skill`, both **read-only** (added to the
     permission allowlist so `plan` mode doesn't block them);
   - the catalog is injected into the system prompt (`# Available skills`) — look
     for the `[skills]` log line.
3. **`skills/`** — two example skills (`python-style`, `git-commit`).
4. **`tests/test_skills.py`** — frontmatter parsing, discovery, catalog, on-demand
   load, unknown-skill error, missing-dir → empty.

## Try it

```bash
python coding_agent.py
# The task tells the agent to load the 'python-style' skill and follow it:
#   [skills] 2 available: python-style, git-commit
#   Tool call: list_skills ...
#   Tool call: load_skill {'name': 'python-style'}   <- the on-demand load
#   Tool call: write_file ... greet.py

python -m unittest tests.test_skills -v
```

Add your own: create `skills/my-skill/SKILL.md` with frontmatter and rerun — it
shows up in the catalog automatically, no code change.

## Takeaways

- Skills = **knowledge as files**, surfaced by a cheap catalog, loaded on demand.
- Keep bodies out of the prompt until needed — that's what makes it scale.
- Loading a skill is read-only, so it's always safe (even in `plan` mode).
