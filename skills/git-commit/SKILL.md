# Git commit messages

- Use the imperative mood in the summary: "Add", "Fix", "Refactor" (not "Added").
- Keep the summary line <= 50 characters; no trailing period.
- Leave a blank line, then a body that wraps around 72 characters.
- Explain **why** the change is needed, not just what changed.
- One logical change per commit; don't mix unrelated edits.
